# SteamCenter

Управление своим аккаунтом Steam через Web API. Программа для Windows 10/11: один `SteamCenter.exe`, установка не нужна.

## Возможности

- **Библиотека.** Пометка «Приватная» сразу для многих игр или для всех: такие игры видите только вы.
  Есть поиск и фильтры («приватные», «открытые», «ни разу не запускались»). Перед каждым изменением
  список приватных игр сохраняется в резервную копию, и его можно вернуть одной кнопкой.
- **Профиль.** Уровень, видимость профиля, дата регистрации, недавние игры, ссылки на страницы Steam
  для редактирования и настроек приватности.
- **Оформление профиля.** Фон, фон мини-профиля, рамка и анимированный аватар из ваших предметов, тема профиля.
- **Список желаемого.** Удаление многих игр сразу.
- **Обновления.** Кнопка «Проверить обновления» в настройках и такая же проверка при запуске
  (релизы репозитория `144bytes/SteamCenter` с файлом `SteamCenter.exe`).

## Вход

Окно программы открывает страницу входа самого Steam: пароль, код Steam Guard или QR-код видит только Steam.
После входа программа берёт токен доступа веб-сессии (`webapi_token`) и хранит его зашифрованным через DPAPI.
Пока Steam помнит этот компьютер, истёкший вход продлевается сам при запуске. Есть и запасной вариант:
вставить токен вручную.

Большинство используемых методов Steam (`IAccountPrivateAppsService`, `IPlayerService/Set*`, `IWishlistService`)
официально не задокументированы: Valve может их изменить.

## Где хранятся данные

Только `%APPDATA%\SteamCenter\`:

| Путь | Что там |
| --- | --- |
| `account.json` | аккаунт и токен (зашифрован DPAPI) |
| `settings.json`, `window.json` | настройки и положение окна |
| `backups\` | резервные копии списка приватных игр (последние 30) |
| `logs\` | журнал |
| `webview\` | данные встроенного браузера (WebView2), в том числе cookies входа в Steam |
| `update\` | скачанное обновление и прежний exe на время замены |

Рядом с exe программа ничего не создаёт.

## Сборка

- `scripts\setup-dev.bat` — один раз на чистом компьютере (Visual Studio Build Tools, Rust, Node.js).
- `scripts\build.bat` — тесты и сборка → `release\SteamCenter.exe`.

Стек: Rust + Tauri 2, интерфейс на React + TypeScript + CSS (Node.js нужен только для сборки, в exe его нет).
